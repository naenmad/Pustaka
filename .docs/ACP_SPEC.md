# Agent Communication Protocol (ACP) Specification — Pustaka



## 1. Overview

This document specifies the local API provided by Pustaka, enabling external AI agents to programmatically interact with the user's workspace.



## 2. Transport & Protocol

- Transport: WebSocket (ws://127.0.0.1:8080)

- Protocol: JSON-RPC 2.0

- Authentication: Optional local token (MVP defaults to open local loopback interface)



## 3. JSON-RPC Methods



### 3.1 pustaka.get_document_tree

Retrieves the full document hierarchy within the workspace.



Request:

{

  "jsonrpc": "2.0",

  "method": "pustaka.get_document_tree",

  "id": 1

}



Response:

{

  "jsonrpc": "2.0",

  "result": {

    "documents": [

      { "id": "doc_1", "title": "Daily Notes", "parent_id": null }

    ]

  },

  "id": 1

}



### 3.2 pustaka.read_document

Reads all content blocks belonging to a document by doc_id.



Request:

{

  "jsonrpc": "2.0",

  "method": "pustaka.read_document",

  "params": { "doc_id": "doc_1" },

  "id": 2

}



Response:

{

  "jsonrpc": "2.0",

  "result": {

    "doc_id": "doc_1",

    "blocks": [

      {

        "id": "blk_1",

        "type": "heading",

        "content": "Welcome to Pustaka"

      },

      {

        "id": "blk_2",

        "type": "paragraph",

        "content": "This is a block-based note."

      }

    ]

  },

  "id": 2

}



### 3.3 pustaka.append_block

Appends a new block to a target document.



Request:

{

  "jsonrpc": "2.0",

  "method": "pustaka.append_block",

  "params": {

    "doc_id": "doc_1",

    "type": "paragraph",

    "content": "New block generated by AI Agent."

  },

  "id": 3

}



Response:

{

  "jsonrpc": "2.0",

  "result": {

    "success": true,

    "block_id": "blk_3"

  },

  "id": 3

}



### 3.4 pustaka.update_block

Updates the content of a specific block by block_id.



Request:

{

  "jsonrpc": "2.0",

  "method": "pustaka.update_block",

  "params": {

    "block_id": "blk_3",

    "content": "Updated block content."

  },

  "id": 4

}



Response:

{

  "jsonrpc": "2.0",

  "result": {

    "success": true

  },

  "id": 4

}



### 3.5 pustaka.delete_block

Removes a block from a document by block_id.



Request:

{

  "jsonrpc": "2.0",

  "method": "pustaka.delete_block",

  "params": {

    "block_id": "blk_3"

  },

  "id": 5

}



Response:

{

  "jsonrpc": "2.0",

  "result": {

    "success": true

  },

  "id": 5

}
